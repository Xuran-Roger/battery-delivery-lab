三条并行工作主线

设备与工程线

设计与制造物流 / 安装单机 / 联动调试稳定交付

关注设备能力、接口、安全条件和版本可追溯。

工艺与质量线

工艺目标 / CTQ验证计划试生产 / 缺陷整改质量与产能确认

关注工艺窗口、良率、能力验证和异常闭环。

项目与协同线

WBS / 风险 / 采购现场Ready / 资源周报 / 变更 / 决策验收 / 文件 / 移交

关注计划、依赖、关键路径、成本与责任边界。

关键区分：FAT偏向供应商工厂的出厂前验证；SAT偏向实际安装现场的约定验证；最终验收/量产移交通常还会涉及连续稳定运行、性能指标、文件和培训等要求。具体定义与签字节点须以合同及验收方案为准。

项目关键门槛（Gate）

关键节点可交付证据典型风险
设计冻结已批准URS、接口与图纸版本需求歧义 / 后期频繁变更
FAT放行测试记录、整改清单、放行签字未验证项带入现场
现场Ready基础设施、物流动线和许可清单设备到厂无法安装
调试完成I/O、联锁、单机和联动测试记录跨设备接口不稳定
SAT通过现场验收协议及实测数据口径不一致 / 证据不全
最终移交性能确认、培训、备件、图纸和遗留问题处理责任边界不清 / 难以维护
